# iPhone Custom Keyboard

Mã nguồn Custom Keyboard Extension cho iPhone.

1. Mở Xcode trên macOS.
2. Tạo iOS App mới.
3. File > New > Target > Keyboard Extension.
4. Đặt target là `LienHoaPinyinKeyboard`.
5. Thay nội dung `KeyboardViewController.swift` bằng source trong thư mục này.
6. Build/sign trên iPhone.
7. Vào Settings > General > Keyboard > Keyboards > Add New Keyboard để bật.

Apple signing/Xcode là bắt buộc để cài keyboard extension thật trên iPhone.
