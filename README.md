# LIÊN HOA PINYIN KEYBOARD

Bộ mã nguồn bàn phím Pinyin tiếng Trung của Liên Hoa Global Education.

## Android
- Android InputMethodService (IME) thật, có thể bật làm bàn phím hệ thống.
- Pinyin + ü + thanh 1–4 + thanh nhẹ.
- v → ü.
- Giao diện Liên Hoa.

## iPhone
- Mã nguồn Custom Keyboard Extension bằng Swift.
- Cần Xcode/macOS để tạo target Keyboard Extension, ký ứng dụng và cài trên iPhone.

## Lưu ý
Đây là bộ source khởi đầu cho bàn phím hệ thống. Chuyển Pinyin → chữ Hán theo từ điển/candidate engine cần bổ sung ở phiên bản tiếp theo.
